# mcpota.com

Static site for MCPOTA, served by GitHub Pages at mcpota.com.

- `index.html`: MCPOTA Privacy Watch home page
- `privacy.html`: privacy policy (mcpota.com/privacy), copied from `docs/privacy.html` in the app repo
- `changelog.html`: release notes (mcpota.com/changelog), built from the app's `whats_new.txt`
- `samples/`: sample executive and technical reports (made-up apps and data)
- `img/`: phone screenshots used on the home page
- `CNAME`: custom domain
